Project Overview

The Coleridge Initiative — Dataset Discovery & NLP Modeling Project explores how Natural Language Processing can automatically identify research datasets referenced in academic publications.

Goal
Build an NLP model that identifies research datasets referenced in academic publications.
Source
Kaggle Coleridge Initiative dataset.
Deliverables
Exploratory data analysis, a cleaned dataset, text embeddings, model training, evaluation metrics, and an automated presentation/report.

NLP Models Used

Multiple modeling approaches were considered, from a strong classical baseline to neural architectures designed for text classification.

01 — Logistic Regression
A fast, interpretable baseline that works particularly well with TF-IDF features.
02 — sep-CNN
A Sentence-piece CNN approach using subword tokens, useful for recognizing short dataset-reference phrases.
03 — BiLSTM
A bidirectional recurrent model that captures contextual information in both directions.
04 — GRU
A memory-efficient recurrent architecture that can model sequential text patterns with fewer gates than an LSTM.
